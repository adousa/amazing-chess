# 07 · UX — the bonus prize

Judged on: **chessboard design · animations & move visualisation · ease of following and
replaying · presentation of results and Elo · "wow factor".**

## Stack (suggestion)
React + Vite + TypeScript, **`@lichess-org/chessground`** (Lichess board: animations, arrows,
highlights, ~10 KB), `chess.js` for client-side logic, types generated from
`contracts/openapi.yaml`. Develop against the Prism mock.

## Pages
| Page | Data (contract) | Must have | Wow |
|---|---|---|---|
| **Ladder** (home) | `GET /ladder` | Steps 1320 → 3190, beaten levels lit, highest Elo beaten big and proud, click → proof game | Animated climb, "next target" card |
| **Match list** | `GET /matches` | Filter by Elo / outcome / version, W/D/L badges | — |
| **Replay** | `GET /matches/{id}`, `/analysis` | Board, ⏮ ◀ ▶ ⏭, autoplay + speed, keyboard arrows, clickable move list, header with Stockfish Elo & result, PGN download | Eval bar, eval graph (click to jump), move badges (`!!` `?` `??`), best-move arrows, agent comments pinned to moves |
| **Live** | SSE `/matches/{id}/events` | Moves appear as played | "Thinking" arrows from `engine.info`, depth/nps ticker, confetti on win |
| **Stats** | `GET /stats` | W/D/L by Elo, colour, version | Engine version timeline vs Elo |
| **New match** | `POST /matches` | Elo slider, colour, count | — |

## Details that make it feel great
- Move & capture sounds, check glow, last-move highlight, smooth piece animation
- Board themes (wood / marble / Lichess blue), piece sets
- Responsive; works on a projector at the demo
- Share link to a specific ply (`/replay/<id>?ply=23`)
- Result screen: "Beat Stockfish at 2200 🎉" with the replay one click away
