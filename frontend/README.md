# frontend/

Simple (throwaway-quality) UI: match list + new-match form, replay with analysis and agent
reports, live view, Elo ladder and stats. Talks to the backend **only** through
[`contracts/`](../contracts/). Vite + React + TypeScript, `@lichess-org/chessground` board,
`chess.js` for position checks. API types are generated from `contracts/openapi.yaml`
(`src/api/schema.d.ts`, git-ignored; regenerated by `dev`/`build`).

```bash
npm install --include=dev   # --include=dev matters if your shell has NODE_ENV=production
npm run dev                 # http://localhost:5173, /api proxied to http://localhost:8000
npm run build               # gen:api + tsc + vite build -> dist/
npm run gen:api             # regenerate TS types from the contract
```

Against the Prism mock (no backend needed):

```bash
npm run mock                # Prism on http://127.0.0.1:4010 (runs with -m false; Node 24 needs it)
npm run dev:mock            # dev server with VITE_API_BASE=http://127.0.0.1:4010
```

`VITE_API_BASE` sets the API base URL (default `/api`). Prism returns schema placeholder data
(e.g. `"fenAfter": "string"`), so the board shows an "invalid FEN" note there; that's expected.

Routes (hash-based): `#/matches`, `#/matches/:id` (replay, or live if running), `#/ladder`, `#/stats`.
Replay keys: ← → Home End.
